# Action Loader

Action Loader is a Blender addon that gives you a persistent list of all of your character's actions, which you can quickly switch between.

This is a fork that substantially differs from the original, in...
- Shrinking the space taken up by most features, and removing extraneous info.
- Dividing functionality into three collapsible menus.
- Adding additional operations, like the ability to apply a base pose before every switch.
